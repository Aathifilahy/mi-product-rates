# MI Product Rates

Full-stack MI Product Rates manager built with Django REST Framework, Oracle-compatible database configuration, and React.

## Project layout

- `backend/` Django API and file uploads
- `frontend/` React rate register
- `postman/` API collection and evidence folder
- `docs/` setup and endpoint reference

## Setup

See [docs/setup.md](docs/setup.md). The backend is configured for Oracle Thin mode through `DB_NAME`, `DB_USER`, and `DB_PASSWORD` environment variables.
